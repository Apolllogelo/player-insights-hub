# Player Insights Hub

Oi Lovable, eu sou um analista de dados do futebol e tenho algumas planilhas que faço a analise individual dos jogadores tanto do elenco quanto para futuras contratações. O meu problema é que são mais de 100 colunas pra cada tipo de jogador e as vezes algo passa batido. Minha ideia é criar um dashboard personalizado que conecte tudo numa aba mais simples e clean
